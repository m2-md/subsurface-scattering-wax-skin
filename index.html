Material that light passes through — real-time SSS for wax and skin

Drag the light azimuth from 178° to 28°: the transmission redness disappears. Use Mode = Thickness to see the map straight out of the bake; white = thick = light has a hard time getting through.

Loop
The thickness map ships baked in the repo; to bake it yourself, run npm run bake:all. For a deterministic measurement add ?measure=1 to the address; when the run finishes a single line, MEASURE {…}, lands in the console. Keep the tab in the foreground during the run — rAF is throttled in a hidden tab and the numbers get polluted.
